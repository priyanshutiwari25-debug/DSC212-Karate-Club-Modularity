# DSC212 – Modularity on the Karate Club Graph

This project contains the Jupyter notebook for the DSC212 Graph Theory research assignment.

## Files

- `DSC212_Karate_Club_Modularity.ipynb` – implementation, tables, discussion and notebook outputs.
- `figures/` – graph snapshots and metric-evolution plots generated by the notebook.
- `requirements.txt` – Python packages needed to run the notebook.

## Run

1. Create and activate a Python environment.
2. Install the packages with `pip install -r requirements.txt`.
3. Start Jupyter and open `DSC212_Karate_Club_Modularity.ipynb`.
4. Select **Restart Kernel and Run All Cells**.

The notebook uses NetworkX's built-in Karate Club graph. It does not need a separate dataset file.

## Method note

The implementation follows the restricted modularity matrix and sign-based eigenvector split described in the assignment handout. If a leading eigenvector has only one sign, it cannot produce a non-empty two-way split under that rule; the notebook records and stops such a branch rather than forcing another threshold.
